# MovieLens SQL Analysis

**Question:** What can I learn about movies, ratings, and tags using SQL alone?

**Data:** The MovieLens `ml-latest-small` dataset: 100,836 ratings and 3,683 tags across 9,742 movies, from 610 users. Files are in `data/`, and a README describes the license and structure.

**Queries (17 in total)**
- Exploring table structure and row counts
- Filtering and sorting (titles starting with a letter, first N rows)
- Aggregations over genres, ratings, and tags
- Joins across movies, ratings, and tags

**Files**
- `project/final_project_movie.sql`: all queries, each with its question as a comment

**Note:** This is an SQL practice project built on a public dataset. The queries are my own answers to the questions in the file.
